
### 🔑 What is JWT?

* **JWT (JSON Web Token)** is just a **string** you give to the client after login.
* It proves:

    1. **Who the user is** (like their email or id).
    2. **That the token was really generated by your server**, not faked.

Example JWT looks like:

```
eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJhc2hAZ21haWwuY29tIiwiZXhwIjoxNzI1MTYyMzM1fQ.abc123
```

---

### 🔨 What `JwtUtil` is doing

This class is a **helper** for:

1. Creating a token (`generateToken`)
2. Reading data back from it (`extractEmail`)

---

### 📂 Code explained line by line

```java
private static final Key key = Keys.secretKeyFor(SignatureAlgorithm.HS256);
```

* JWT needs a **secret key** so no one else can fake tokens.
* `HS256` is the signing algorithm (HMAC-SHA256).
* This `key` is used to **sign** and **verify** the token.

---

```java
private static final long EXPIRATION = 1000 * 60 * 60; // 1 hour
```

* Tokens shouldn’t last forever (security risk).
* This sets expiry = 1 hour (in milliseconds).

---

```java
public static String generateToken(String email) {
    return Jwts.builder()
            .setSubject(email)          // Put email into the token body
            .setIssuedAt(new Date())    // When was it created
            .setExpiration(new Date(System.currentTimeMillis() + EXPIRATION)) // expiry time
            .signWith(key)              // sign with our secret key
            .compact();                 // generate final string (JWT)
}
```

* Input = user’s email.
* Output = JWT string (to send back to frontend after login).
* The frontend will now include this JWT in **headers** for future API calls.

---

```java
public static String extractEmail(String token) {
    return Jwts.parserBuilder()
            .setSigningKey(key)     // use same key to check if token is valid
            .build()
            .parseClaimsJws(token)  // parse JWT
            .getBody()
            .getSubject();          // get email back
}
```

* Input = token string received from client.
* Checks if token is **valid** (not tampered with + not expired).
* Returns the **email** stored inside.

---

### 📌 Flow in practice

1. User logs in with email/password.
2. Server checks DB → credentials valid.
3. Server calls:

   ```java
   String token = JwtUtil.generateToken(email);
   ```

   and sends this token to frontend.
4. Later, frontend sends token in request header:

   ```
   Authorization: Bearer <token>
   ```
5. Server checks:

   ```java
   String email = JwtUtil.extractEmail(token);
   ```

   → Now you know **which user** made the request.

---

⚡ In short:

* **`generateToken()`** → create secret pass (JWT) for logged-in user.
* **`extractEmail()`** → check if token is real + get user identity back.
